# 基于 Bloomberg 数据的多资产投资组合优化

[English README](README.md) · [研究 notebook](notebooks/portfolio_research.ipynb) ·
[完整报告](docs/report.pdf) · [演示稿](docs/presentation.pdf)

## 研究什么

以澳大利亚养老金资产配置为背景，使用九类 Bloomberg 资产指数，研究历史数据能否支持可靠的长期配置，
以及更频繁的战术调整、随财富变化的动态配置能否增加价值。共同样本为 2006 年 1 月至 2026 年 8 月的
248 个月收益，涵盖股票、地产、基础设施、对冲基金、债券和现金。

## 做了什么

从数据频率与质量检查出发，估计收益和协方差，构建有效前沿及三类增长／防御比例的战略组合；
利用 Monte Carlo 与 Bootstrap 区分计算误差和估计不确定性，再做样本外回测、换手与交易成本分析。
扩展研究采用三期动态规划，按财富状态求解配置，并与相同条件的固定权重效用组合公平比较。

## 主要结果

- 权重的 Monte Carlo 距离约为 0.75%，而 Bootstrap 平均距离为 42.6%，说明估计不确定性远大于数值求解误差。
  这里的百分比是配置距离，不是亏损率。
- 基准 TAA 在四次两年测试中都落后于固定平衡 SAA，额外换手使成本后的表现更差。
- 三个月动态模型相对同约束静态组合的 CE 增益约为 -0.01 个初始财富基点，配对模拟区间包含零，
  因而没有明确的额外效用收益证据。这不表示动态投资在所有时期都不如固定 SAA。
